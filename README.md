# Fastify starter

A minimal [Fastify](https://fastify.dev) server.

## Run it locally

```sh
npm install
npm start
```

Then open http://localhost:8080. `GET /health` answers `ok` for health checks.

## Deploying

| Step | Command |
| --- | --- |
| Build | none |
| Start | npm start |

## Environment variables

| Variable | Meaning |
| --- | --- |
| `PORT` | Port to listen on. Default: 8080. |
